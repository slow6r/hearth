# 0002 — Скрыть экран выбора операторов

## Что делаем
Пункт «Операторы сети» (Network / Server operators) убираем из настроек: не «выключаем
всех операторов», а прячем сам экран.

## Почему
ТЗ §8.2 п.2. Выключенный оператор — это состояние, которое можно случайно включить.
Отсутствующий экран включить нельзя. Приложение должно быть **неспособно** уйти в
публичную сеть, а не просто настроено не уходить (§1.2).

## Точка интеграции
```bash
rg -n "operator|Operator" apps/multiplatform/common/src/commonMain/kotlin --glob '*Settings*'
```

Убрать пункт из списка настроек (одна строка в composable). Сам экран не удаляем:
удаление файла даёт конфликт при каждом ребейзе, а недостижимый экран — нет.

## Проверка
- A6: экран операторов отсутствует в UI.
