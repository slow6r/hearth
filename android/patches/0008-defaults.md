# 0008 — Приватный роутинг и исчезающие сообщения по умолчанию

## Что делаем
1. Private message routing = `Always` по умолчанию.
2. Исчезающие сообщения 7 дней для новых контактов и групп.
3. Биометрия/пароль приложения предлагается при первом запуске (шаг онбординга).

## Почему
ТЗ §8.2 п.5 и п.6. Приватный роутинг: релей не должен видеть, кто с кем. Исчезающие
сообщения ограничивают ущерб от потери устройства; 7 дней — компромисс между этим и
семейной привычкой листать историю. Биометрия при первом запуске, а не «когда-нибудь в
настройках», потому что второй вариант не случается.

## Точка интеграции
```bash
rg -n "privateRouting|SMPProxyMode|smpProxyMode" apps/multiplatform/common/src
rg -n "ttl|disappearing|timedMessages" apps/multiplatform/common/src --glob '*Preference*'
```

Меняем **значения дефолтов**, а не логику. Пользователь может усилить настройку, но не
ослабить приватный роутинг ниже `Always`.

## Проверка
- Ручная: новый контакт создаётся с TTL 7 дней.
- `HearthBundle.validate` на устройстве требует `privateRouting=always`.
