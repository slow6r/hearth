# 0010 — Отключить in-app обновления

## Что делаем
Проверку обновлений внутри приложения отключаем. Канал доставки — собственный
F-Droid-репозиторий на `hearth-node`, доступный только из WG.

## Почему
ТЗ §8.2 п.9. Проверка обновлений — исходящее соединение к третьей стороне, то есть
ровно то, чего в контуре быть не должно. Плюс она раскрывает факт использования сборки.

Fallback, если F-Droid недоступен: APK передаётся через сам мессенджер, подпись
проверяется вручную (`apksigner verify --print-certs`) по известному отпечатку.

## Точка интеграции
```bash
rg -n "checkForUpdates|AppUpdate|updateChannel" apps/multiplatform
```

Отключить вызов и убрать пункт из настроек.

## Проверка
- `scripts/verify-apk.sh`: в dex нет обращений к GitHub API / apps.simplex.chat.
