# 0007 — Доставка Instant, без пуш-сервера

## Что делаем
Режим доставки — `Instant` (foreground-сервис с постоянным соединением). `Periodic` и
`Push` недоступны в UI. Notification server не настраивается. В шторке — только
«Новое сообщение», без отправителя и текста.

## Почему
ТЗ §8.2 п.4 и §3.1 «Утечка метаданных через пуши». Пуш идёт через инфраструктуру
Google/Apple — третью сторону, которой в модели угроз места нет. Постоянное соединение
внутри WG делает пуши ненужными.

Цена решения (принимается осознанно): фоновый сервис расходует батарею, а без VPN
сообщения не приходят вовсе (ТЗ §14, риск «WG-только доставка»). Это надо сказать
пользователю прямо в онбординге — `HearthOnboardingText.VPN_HINT`.

## Точка интеграции
```bash
rg -n "NotificationsMode|ntfMode|SMP_NTF|notificationServer" apps/multiplatform/common/src
```

Дефолт → `Instant`; остальные варианты не отображать; экран сервера уведомлений скрыть
(как в 0002 — прячем пункт, не удаляем экран).

## Проверка
- Ручная: в настройках уведомлений нет выбора режима.
- `rg "ntf[0-9]*\.simplex\.im" apps/` — пусто.
