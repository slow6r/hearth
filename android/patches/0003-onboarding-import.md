# 0003 — Онбординг: импорт bundle по QR

## Что делаем
Перед стандартным онбордингом upstream показываем один экран: «Отсканируй QR настройки
узла». После успешного импорта — обычный upstream-флоу создания профиля.

## Почему
ТЗ §8.2 п.7 и §1.4: новое устройство подключается за ≤ 5 минут по одному QR.

## Точка интеграции
```bash
rg -n "OnboardingStage|onboardingStage" apps/multiplatform/common/src/commonMain/kotlin
```

1. Добавить первую стадию в enum онбординга (одна строка).
2. Отрисовать экран из overlay (`HearthOnboardingText` + upstream-сканер).
3. Реализовать `HearthBundleApplier` в android-исходниках против controller API
   пинованного тега: установка серверов, сетевые дефолты, запись device id.

**Сканер QR брать upstream'овский.** Своя камера = новая зависимость, новое разрешение
и новая поверхность атаки ради экрана, который используется один раз в жизни устройства.

## Проверка
- Юнит-тесты `HearthBundleTest` (парсинг, валидация, применение ровно один раз).
- Ручная: чистая установка → скан → ровно один SMP и один XFTP сервер в настройках.
