# hearth

Закрытый мессенджер для семьи и близких на домашнем сервере.

Под капотом — [SimpleX Chat](https://github.com/simplex-chat/simplex-chat): сообщения
шифруются от устройства до устройства, номер телефона не нужен. От обычного SimpleX
отличие одно: все серверы свои и стоят дома, а не у третьих лиц.

## Как это устроено

- **Домашний узел** — мини-ПК с релеями SimpleX (сообщения и файлы) и TURN-сервером
  для звонков. Серверный код SimpleX не изменён ни на строку.
- **`hearthd`** — наш демон на Rust. Следит, чтобы узел сам ничего не отправлял
  наружу, проверяет целостность бинарей, делает зашифрованные бэкапы, заводит
  устройства.
- **`hearthctl`** — консольная админка к нему.
- **Приложение Hearth** — клиент SimpleX с нашими настройками: знает адрес узла, не
  ходит на публичные серверы, обновляется с узла.

Человек ставит приложение, вводит выданный ему код доступа — и он в контуре.

## Что в репозитории

| Каталог | Что там |
|---|---|
| `hearthd/` | демон и `hearthctl` (Rust) |
| `relays/` | конфиги стоковых релеев SimpleX и TURN |
| `android/` | наши правки поверх клиента SimpleX (Android, Windows) и скрипты сборки |
| `ios/` | то же для iPhone: overlay, описания патчей, сборка и выкладка в App Store |

| `tests/` | приёмочные проверки узла |

## Быстрый старт

Собрать `hearthd`:

```bash
cd hearthd
cargo test
cargo build --release --target x86_64-unknown-linux-musl
```

Поднять узел — по шагам в [docs/runbook-deploy.md](docs/runbook-deploy.md).

Выписать коды доступа и раздать их лично:

```bash
hearthctl invite create --count 5 --uses 1 --write-codes codes.txt
hearthctl invite revoke <id>    # если код ушёл не туда
```

Выпустить новую версию приложения — [docs/runbook-release.md](docs/runbook-release.md).

## Каждый день

```bash
hearthctl status        # всё сразу: сервисы, egress, бэкап, устройства
hearthctl egress        # исходящие соединения узла — должно быть 0
hearthctl alerts        # что случилось
hearthctl device list   # кто подключён
```

Остальное — `hearthctl --help`.

## Ограничения

- **Узел один.** Пока он выключен, сообщения ждут на телефонах и доходят, когда узел
  вернётся.
- **Факт общения не скрыт.** Наблюдатель на канале видит, что телефон связывается с
  узлом, и объём трафика, — но не содержимое.
  [ADR 0007](docs/adr/0007-public-relay-no-vpn.md)
- **iOS-приложение в работе** ([ios/](ios/README.md), выпуск через App Store по
  ссылке). Пока его нет, на iPhone ставится обычный SimpleX и настраивается вручную:
  [docs/ios-checklist.md](docs/ios-checklist.md).
- **Веб-интерфейса нет** — только `hearthctl`.
