# 0101 — Адрес push-сервера из окружения

## Что делаем
`_defaultNtfServers` больше не список серверов SimpleX. Ядро берёт адреса из переменной
окружения `HEARTH_NTF_SERVERS` (адреса `ntf://…` через пробел), которую приложение
выставляет до запуска ядра. Переменной нет или она не разбирается — **push-серверов нет
вовсе**, а не серверы SimpleX.

## Почему
[ADR 0016](../../docs/adr/0016-own-push-server.md). Адрес push-сервера на iOS живёт
только в Haskell: мобильный конфиг (`defaultMobileConfig`) его не перекрывает, команды
для него у ядра нет, а `setNtfServers` агента ядро чата не вызывает. Без правки
приложение отдавало бы токен устройства и расписание уведомлений `ntf3/ntf4.simplex.im`.

Почему окружение, а не адрес узла прямо в исходнике: ядро собирается часами и только на
Apple Silicon. Адрес, зашитый в Haskell, означал бы пересборку ядра при любой смене
узла; окружение оставляет ядро одинаковым для всех сборок одного тега.

Почему пустой список, а не upstream-серверы, при ошибке: ошибка в адресе должна давать
«уведомления не работают», а не тихую утечку третьей стороне — то же правило, что для
ICE (`android/patches/0004`).

## Точка интеграции
```bash
rg -n "_defaultNtfServers" src
```
Одно определение в `Library/Commands.hs`, использования в `Chat.hs` (`presetServers.ntf`)
и `Terminal.hs` не трогаются. Значение — CAF под `NOINLINE`: читается один раз при первом
обращении, то есть при создании контроллера в `chat_migrate_init_key`. Отсюда требование
к Swift-стороне (0103): переменная выставляется **до** `haskell_init*`, во всех трёх
процессах — приложение, NSE, Share Extension.

Сборка идёт с `-Werror=name-shadowing`, поэтому в правке нет локальных имён.

## Проверка
- `rebase-upstream.sh` печатает дифф этого файла и останавливается на любом другом `.hs`.
- На узле после первого запуска: в журнале ntf-server регистрация токена
  (`/_ntf register`) приходит к нам; `ss -tn` на телефоне не показывает `ntf*.simplex.im`.
- Сборка без `HEARTH_NTF_SERVERS`: экран уведомлений показывает ошибку регистрации
  токена, а не сервер SimpleX.
