# 0106 — ICE: только свой coturn, без запасных публичных

## Что делаем
- `WebRTCClient.defaultIceServers` — пустой список вместо `stun/turn.simplex.im`.
- Список ICE пишется из bundle и обновляется с узла при каждом старте (0105).
- Экран ручной правки ICE скрыт (`HEARTH_ICE_EDITABLE = false`).

## Почему
android/patches/0004. На iOS ловушка та же: `parseRTCIceServers` возвращает `nil` на
одной плохой записи, и `initializeCall` берёт `defaultIceServers`. У upstream это
публичные серверы — тихая утечка адреса третьей стороне. Пустой запасной список
превращает её в несостоявшийся звонок.

`HearthIce.requireEntry` проверяет записи и правилами узла, и правилами именно iOS-парсера
(`URL(string:)`, хост и порт обязательны, пустой path).

## Точка интеграции
```bash
rg -n "defaultIceServers|getWebRTCIceServers|RTCServers\(\)" apps/ios/Shared
```

## Проверка
- A8: звонок между сетями, среди кандидатов только узел.
- `rg "stun\.simplex\.im|turn\.simplex\.im" apps/ios/Shared` — пусто.
