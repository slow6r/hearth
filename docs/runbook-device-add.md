# Runbook: добавление устройства

ТЗ §10.3. Критерий (§1.4 п.3): **≤ 5 минут по одному QR**.

## Порядок

### 1. Зарегистрировать устройство на узле

```bash
hearthctl device add "Мама — Pixel 8" --platform android
```

Команда создаёт запись (`mama-pixel-8`) и сразу печатает QR прямо в терминал.
Ограничение — 20 активных устройств (ТЗ §1.1); отозванные слоты освобождают.

### 2. Подключить устройство к семейному WG

Существующая процедура на UDM Pro. Проверка на телефоне: узел `10.66.10.10` пингуется.

Без VPN мессенджер не работает вообще — это дизайн, а не поломка (ТЗ §14). На Android
имеет смысл включить always-on VPN с kill-switch.

### 3. Поставить APK

Из внутреннего F-Droid-репозитория на `hearth-node` (доступен только из WG).
Fallback — APK через существующий чат с проверкой подписи:

```bash
apksigner verify --print-certs hearth-release.apk   # отпечаток сверить с известным
```

### 4. Скан QR

Первый экран приложения — «Отсканируй QR настройки узла». После скана в настройках
должен быть **ровно один** SMP-сервер и один XFTP, оба на `10.66.10.10`.

QR показывается на экране администратора и никуда не сохраняется: в нём пароли релеев
(ТЗ Приложение B). Если QR всё же был записан в файл (`--write-png`) — удалить сразу
после подключения.

### 5. Обмен контактами — только лично

ТЗ §10.3 п.5: одноразовая ссылка или QR **при личной встрече**. Не через другие
мессенджеры — иначе приватность контура упирается в приватность WhatsApp.

### 6. Добавление в семейную группу

Делает любой существующий участник, изнутри приложения.

## iOS и Desktop

Стоковое приложение не умеет импортировать серверы одним QR, поэтому:

```bash
hearthctl device add "Папа — iPhone 15" --platform ios
hearthctl device checklist papa-iphone-15
```

Печатается чек-лист из 6 шагов (ТЗ §9), сгенерированный из того же состояния узла, что и
bundle, — расходиться они не могут. Подробности: [ios-checklist.md](ios-checklist.md).

## Проверка

```bash
hearthctl device list
hearthctl health
```

На устройстве: отправить сообщение и получить ответ.
